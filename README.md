Chemical Quality Control Analysis

Présentation du projet

Ce projet consiste à analyser des données de contrôle qualité chimique à l'aide de Python.

L'objectif est de vérifier la conformité des concentrations par rapport aux limites spécifiées, de calculer des statistiques descriptives et de générer un rapport Excel avec des graphiques.

Outils utilisés

- Python
- Pandas
- NumPy
- Matplotlib
- OpenPyXL
- Excel

Méthodologie

1. Génération d'un jeu de données simulées de 300 échantillons.
2. Vérification de la conformité des concentrations.
3. Calcul des statistiques descriptives.
4. Visualisation de la distribution des concentrations.
5. Génération d'un rapport Excel automatisé.

Résultats

- Nombre total : 300 échantillons
- Échantillons conformes : 289
- Échantillons non conformes : 11
- Taux de conformité : 96,33 %

Limites de spécification : 9,5 – 10,5

 Project Overview

This project focuses on chemical quality control data analysis using Python.

The objective is to assess sample conformity against specified concentration limits, calculate descriptive statistics, visualize the results, and generate an automated Excel report.

Dataset

The dataset contains 300 simulated samples. It does not represent real laboratory measurements.

Tools

Python, Pandas, NumPy, Matplotlib, OpenPyXL and Excel.

Key Results

- Total samples: 300
- Conforming samples: 289
- Non-conforming samples: 11
- Conformity rate: 96.33%

Specification limits: 9.5 – 10.5
